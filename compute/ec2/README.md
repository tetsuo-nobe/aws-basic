# EC2 インスタンス作成ハンズオン

AWS マネジメントコンソールを使用して EC2 インスタンスを作成し、Session Manager で接続するまでの手順です。

## 前提条件

- AWS アカウントを持っていること
- IAM ロール `my-role-for-session-manager` が作成済みであること
  - `AmazonSSMManagedInstanceCore` ポリシーがアタッチされていること
  - CloudShell で下記を実行することで、このロールを作成可能
  - ```
    curl -s https://tnobep-demo-public.s3.ap-northeast-1.amazonaws.com/create_ssm_role.sh | bash
    ```
- デフォルト VPC が存在すること

---

## サインイン

1. AWS アカウントにアクセス: [こちら](https://d-9567586b55.awsapps.com/start) を右クリックしてブラウザの新しいタブで開きます。
2. ユーザー名とパスワード、使用する許可セットはインストラクターから案内します。
3. 東京リージョンを使用します。

---

## 1. EC2 インスタンスの作成

### 1-1. EC2 ダッシュボードを開く

1. AWS マネジメントコンソールにサインインする
1. ページ上部で、東京リージョンを選択する
    - **「アジアパシフィック（東京）」** と表示されていれば OK 
1. 上部の検索バーに `ec2` と入力し、**EC2** サービスを選択する
1. 左メニューで 「インスタンス」の下にある **「インスタンス」** をクリックする
1. **「インスタンスを起動」** ボタンをクリックする

### 1-2. 名前とタグ

1. **「名前」** に任意のインスタンス名を入力する（例：`my-handson-instance`）

### 1-3. AMI の選択

1. **「Amazon マシンイメージ (AMI)」** はデフォルトの「Amazon Linux 2023 AMI」のままにする
1. アーキテクチャは「64 ビット (x86)」のままにする

### 1-4. インスタンスタイプの選択

1. **「インスタンスタイプ」** のドロップダウンから `t3.micro` を選択する

### 1-5. キーペア（ログイン）

1. **「キーペア名」** のドロップダウンから **「キーペアなしで続行」** を選択する

> SSH ではなく Session Manager で接続するため、キーペアは不要です。

### 1-6. ネットワーク設定

1. **「からの SSH トラフィックを許可」** の **チェックを解除** する
1. **「インターネットからの HTTP トラフィックを許可」** を **チェックする**

> Session Manager は SSM エージェントが HTTPS (443) でアウトバウンド通信を行うため、インバウンドルールは不要です。

### 1-7. ストレージの設定

1. デフォルトのまま変更しない（8 GiB gp3）

### 1-8. 高度な詳細

1. **「高度な詳細」** セクションを展開する
1. **「IAM インスタンスプロフィール」** のドロップダウンから `my-role-for-session-manager` を選択する

### 1-9. インスタンスの起動

1. ページ右下の **「インスタンスを起動」** ボタンをクリックする
1. **「すべてのインスタンスを表示」** をクリックする
1. **「ステータスチェック」** が「3/3 のチェックに合格しました」になるまで待つ（3〜4 分程度）

---

## 2. Session Manager で接続する

### 2-1. EC2 コンソールから接続

1. EC2 ダッシュボードの「インスタンス」画面で、作成したインスタンスの名前の左側のチェックボックスをチェックする
1. **「接続」** ボタンをクリックする
1. **「SSM セッションマネージャー」** を選択する
1. **「接続」** ボタンをクリックする

ブラウザ上でターミナルセッションが開き、インスタンスに接続できます。

1. 下記のコマンドを実行する

```bash
cd  ~
```

---

## 3. Python Web アプリケーションの作成

Session Manager で接続した状態で、以下のコマンドを順に実行します。

### 3-1. Flask のインストール

1. pip をインストールする

```bash
sudo dnf install -y python3-pip
```

2. Flask をインストールする

```bash
sudo pip3 install flask
```

> インストール後に WARNING が表示されても無視して下さい。

### 3-2. アプリケーションファイルの作成

1. Web アプリケーションのコードを作成する

```bash
cat << 'EOF' > ~/app.py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def hello():
    return "<h1>Hello EC2!</h1>"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=80)
EOF
```

### 3-3. アプリケーションの起動

1. Flask アプリケーションを起動する

```bash
sudo python3 ~/app.py &
```

> ` Running on all addresses (0.0.0.0)` と表示されれば起動成功です。

> プロンプトが戻らない場合は、Enter キーを押下してみてください。

2. ローカルで動作確認する

```bash
curl http://localhost
```

> `<h1>Hello EC2!</h1>` と表示されれば成功です。

---

## 4. ブラウザからアクセスする

1. パブリック IPv4 アドレスを取得して、アクセス用の URL を表示する

```bash
TOKEN=$(curl -s -X PUT "http://169.254.169.254/latest/api/token" -H "X-aws-ec2-metadata-token-ttl-seconds: 21600")
echo "http://$(curl -s -H "X-aws-ec2-metadata-token: $TOKEN" http://169.254.169.254/latest/meta-data/public-ipv4)"
```

> EC2 インスタンスは内部からメタデータサービス（169.254.169.254）に問い合わせることで、自身の情報を取得できます。

2. 表示された URL をコピーして、ブラウザのアドレスバーに貼り付けてアクセスする

> 「Hello EC2!」と表示されれば成功です。

> http プロトコルでのアクセスが制限されている環境では表示できない場合があります。
---

## 5. クリーンアップ

ハンズオン終了後、不要な課金を防ぐためにインスタンスを終了します。

1. Session Manager のブラウザのタブを閉じる
1. EC2 ダッシュボードの **「インスタンス」** 画面で、作成したインスタンスを選択する
2. **「インスタンスの状態」** ドロップダウンから **「インスタンスを終了 (削除)」** を選択する
3. 確認ダイアログで **「終了 (削除)」** をクリックする
