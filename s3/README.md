# Amazon S3 ハンズオン

あらかじめ用意されたパブリックアクセス可能な S3 バケットに、各自が編集した `index999.html` をアップロードし、Web ブラウザからアクセスするまでを体験するハンズオンです。

## 前提条件

- このリポジトリと同じフォルダにある `index999.html` をダウンロードしておく
- アップロード先のバケット（`tnobect-public-sandbox` で始まる名前）はインストラクターが事前に用意済み

---

## サインイン

1. 個人に割り振られた ID（番号）を確認します。
2. AWS アカウントにアクセス: [こちら](https://d-9567586b55.awsapps.com/start)を右クリックして新しいタブで開きます。
3. ユーザー名とパスワード、使用する許可セットはインストラクターから案内します。
4. 東京リージョン（`ap-northeast-1`）を使用します。

---

## 1. index999.html の編集

### 1-1. ファイルをダウンロードする

1. このリポジトリと同じフォルダにある `index999.html` を自分の PC にダウンロードする

### 1-2. メッセージを編集する

1. ダウンロードした `index999.html` をテキストエディタで開く
2. **226 行目** の以下の行を探す

    ```html
    <p>（ここにお好きなメッセージを入力）</p>
    ```

3. `（ここにお好きなメッセージを入力）` の部分を、自分の好きなメッセージに書き換える

    ```html
    <p>私の初めての S3 ページです！</p>
    ```

4. ファイルを保存する

### 1-3. ファイル名を変更する

1. ファイル名の `999` の部分を、自分の ID（番号）に変更する
    - 例：ID が `101` の場合 → `index101.html`
    - 例：ID が `210` の場合 → `index210.html`

> 各自でファイル名を変えることで、同じバケット内でもファイルが上書きされずに区別できます。

---

## 2. バケットへのアップロード

### 2-1. S3 コンソールを開く

1. 検索バーに `s3` と入力し、**S3** サービスを選択する

### 2-2. 用意されたバケットを開く

1. バケット一覧から `tnobect-public-sandbox` で始まるバケットをクリックする

### 2-3. オブジェクトをアップロードする

1. **「アップロード」** ボタンをクリックする
2. **「ファイルを追加」** をクリックし、編集した `index<自分のID>.html`（例：`index101.html`）を選択する
3. **「アップロード」** ボタンをクリックする
4. アップロードが成功することを確認する
5. **「閉じる」** をクリックしてバケットの画面に戻る

---

## 3. Web ブラウザからのアクセス確認

### 3-1. オブジェクト URL を確認する

1. アップロードしたファイル一覧から `index<自分のID>.html`（例：`index101.html`）をクリックする
2. **「プロパティ」** タブを開く
3. **「オブジェクト URL」** に表示されている URL をコピーする

> オブジェクト URL の形式：`https://tnobect-public-sandbox-xxxx.s3.ap-northeast-1.amazonaws.com/index101.html`

### 3-2. ブラウザからアクセスする

1. ブラウザの新しいタブを開く
2. コピーしたオブジェクト URL を貼り付けてアクセスする
3. **編集した内容（自分のメッセージ）を含むページが正常に表示される**ことを確認する

> このバケットはインストラクターがバケットポリシーでパブリックアクセスを許可済みのため、そのままブラウザで閲覧できます。

---

## 4. クリーンアップ

ハンズオン終了後、自分がアップロードしたファイルを削除します。

> バケット自体はインストラクターが管理しているため削除しません。**自分がアップロードした `index<自分のID>.html` のみ** を削除してください。

1. バケット内のオブジェクト一覧から、自分がアップロードした `index<自分のID>.html` を選択する
2. **「削除」** ボタンをクリックする
3. 確認画面で `完全に削除` と入力し、**「オブジェクトの削除」** をクリックする
4. **「閉じる」** をクリックする

---

## まとめ

このハンズオンで学んだことを振り返りましょう。

| 学んだこと | 内容 |
|-----------|------|
| オブジェクトの編集 | HTML ファイルを編集し、個別のファイル名を付ける |
| オブジェクトのアップロード | コンソールから用意されたバケットへファイルをアップロード |
| オブジェクト URL | パブリックアクセス可能なバケットでは URL で直接閲覧できる |
| パブリックアクセス | バケットポリシー設定済みのため署名なし URL でアクセス可能 |
| クリーンアップ | 自分がアップロードしたオブジェクトの削除 |
